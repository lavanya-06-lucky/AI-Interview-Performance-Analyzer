# AI-Interview-Performance-Analyzer
An AI-powered interview performance analyzer that evaluates recorded videos based on eye contact, posture, and speech. It generates individual and overall performance scores along with simple feedback to help users improve their interview skills. Built with Python, Flask, OpenCV, SpeechRecognition, and Librosa.

Technologies Used
- Python
- Flask
- OpenCV
- SpeechRecognition
- Librosa
- HTML
- CSS
- JavaScript
